# MASKA XITERS Auto-Updates

GitHub payloads for **MaskaXitersLoader** and **INTERNAL MAX** (`brutal` channel).

- Manifest: `updates/manifest.json`
- Loader exe: `payloads/loader/MaskaXitersLoader.exe`
- Internal max: `payloads/brutal/Client.dll` (no native `.so` libraries in updates)

Publish from the MASKA project using `LOADER\examples\Scripts\Publish-Maska-All.ps1`.
